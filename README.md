# حملة لعجايلية عبد الحفيظ — بلدية تاوة

صفحة حملة انتخابية واحدة (Landing Page) مبنية بـ HTML/CSS/JavaScript خالص، بلا أي إطار عمل
وبلا اعتماد على مكتبات خارجية. المحتوى يُقرأ من ملفات **Markdown** داخل مجلد `data/`،
وتدعم الصفحة **الوضع النهاري والليلي**، وهي جاهزة للنشر على **GitHub Pages**.

## تعديل المحتوى (بدون لمس الكود)

كل النصوص في `data/`. افتح الملف، عدّل، ثم أعد تحميل الصفحة.

### `data/site.md`

الجزء بين `---` هو بيانات الواجهة (Front Matter)، وما بعده نص Markdown يظهر في قسم «عن المرشح».

```yaml
title: لعجايلية عبد الحفيظ        # الاسم في الأعلى
title_highlight: عبد الحفيظ       # الجزء الملوّن من الاسم
role: محامٍ
party: حزب التجمع الوطني الديمقراطي
party_short: RND
municipality: بلدية تاوة
election: انتخابات المجلس الشعبي البلدي — بلدية تاوة
badge: جيل جديد.. رؤية رقمية
slogan: معاً من أجل تنمية تاوة
tagline: جملة تعريفية قصيرة
cta_primary: انضم إلى الحملة
cta_secondary: البرنامج الانتخابي
join_title: كن جزءاً من التغيير
join_text: نص تعريفي بجانب النموذج
form_endpoint: ""                # اتركه فارغاً للوضع التجريبي (انظر أدناه)
```

`road` · `network` · `users` · `rocket` · `health` · `leaf` · `spark` · `vote`

### صورة المرشح

الصورة الحالية هي `assets/img/abdhafid.jpeg` (ملصق الحملة، 1080×1454).
لاستبدالها، ضع ملفاً جديداً في `assets/img/` وحدّث السطر في `index.html`:

```html
<img src="assets/img/abdhafid.jpeg"
     alt="ملصق حملة لعجايلية عبد الحفيظ — مرشح بلدية تاوة" width="1080" height="1454">
```

> مجلد `imag/` في الجذر هو مجلد الصور المصدرية، وهو مستثنى من Git.

### بطاقة المشاركة الاجتماعية (Messenger / WhatsApp / Facebook)

الصورة المستخدمة في معاينة الرابط هي `assets/img/og-cover.png` بمقاس **1200×630** (نسبة 1.91:1).
هذه النسبة ضرورية: الصور العمودية تجعل Messenger يعرضها كصورة مستقلة،
فتُفتح الصورة وحدها بدل الموقع عند النقر عليها.

لتعديل البطاقة: عدّل `tools/og-cover.html` ثم أعد توليد الصورة:

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu `
  --hide-scrollbars --force-device-scale-factor=1 --window-size=1200,630 `
  --screenshot="assets\img\og-cover.png" "http://localhost:8080/tools/og-cover.html"
```

بعد أي تغيير في البطاقة، غيّر `?v=2` في وسوم `og:image` داخل `index.html` لكسر تخزين فيسبوك المؤقت.

**مهم:** شارك رابط الصفحة `https://adjailia.github.io/campaign-taoua/` وليس ملف الصورة.
إرسال الصورة كملف لا يمكن أن يفتح الموقع — الصورة ليست رابطاً.

## الوضع الليلي

- زر في أعلى الصفحة يبدّل بين الوضعين ويحفظ الاختيار في `localStorage`.
- في أول زيارة يتبع إعداد النظام (`prefers-color-scheme`).
- لا يوجد وميض ألوان عند التحميل (يُطبَّق الوضع قبل رسم الصفحة).
- كل الألوان معرّفة كمتغيرات CSS في أعلى `assets/css/styles.css`، ويمكن تعديل الهوية من مكان واحد.

## النموذج «قاعدة بيانات Markdown»

### الوضع التجريبي (الافتراضي)

عند ترك `form_endpoint` فارغاً:

1. يتحقق النموذج من الاسم ورقم الهاتف الجزائري والموافقة على الخصوصية.
2. يُحفظ التسجيل في `localStorage` الخاص بالمتصفح (لا يغادر جهاز المستخدم).
3. افتح الصفحة مع `?admin=1` لرؤية التسجيلات وتنزيلها كملف Markdown:

```
index.html?admin=1
```

زر **«تنزيل submissions.md»** يولّد الملف بهذا الشكل، وتضعه في `data/`:

```md
| # | الاسم الكامل | الهاتف | الموافقة | التاريخ |
|---:|---|---|---|---|
| 1 | محمد أمين | 0550123456 | نعم | 2026-11-08T10:12:00.000Z |
```

> `data/submissions.md` مضاف إلى `.gitignore` لأنه يحتوي معطيات شخصية.
> لا ترفعه إلى مستودع عام.

### الوضع الحقيقي (استقبال التسجيلات من كل الزوار)

الموقع ساكن (Static)، لذلك لا يمكنه الكتابة في ملفات الخادم. الحل الأبسط:

1. أنشئ Google Apps Script بسيطاً يستقبل `POST` ويكتب في Google Sheets.
2. انشر السكربت كـ Web App (صلاحية: Anyone).
3. ضع الرابط في `form_endpoint` داخل `data/site.md`.

بدائل جاهزة بلا كود: **Formspree** أو **Netlify Forms** أو **Cloudflare Worker**.

## المعاينة المحلية

المتصفح يمنع `fetch` لملفات `.md` عند فتح الصفحة بالنقر المزدوج (`file://`).

**Windows:** انقر نقراً مزدوجاً على `serve.bat` ثم افتح <http://localhost:8080>.

**أو يدوياً:**

```bash
python -m http.server 8080
# أو
npx serve .
```

**VS Code:** إضافة *Live Server* ← زر Go Live.

## النشر على GitHub Pages

### الطريقة 1 — من الفرع مباشرة (المستخدمة حالياً)

1. أنشئ مستودعاً على GitHub وارفع المشروع:

```bash
git init -b main
git add .
git commit -m "نسخة أولى من صفحة الحملة"
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

2. من المستودع: **Settings → Pages → Source = Deploy from a branch**.
3. اختر **Branch = main** و **Folder = / (root)** ثم احفظ.
4. يظهر الرابط بعد دقيقة تقريباً: `https://USERNAME.github.io/REPO/`.

ملف `.nojekyll` موجود حتى لا يعالج GitHub ملفات المشروع.

> إذا كان لديك توكن بصلاحية `workflow` وترغب في النشر التلقائي عبر GitHub Actions،
> أعد ملف `.github/workflows/pages.yml` ثم اضبط **Source = GitHub Actions**.

### الطريقة 2 — نفس الخطوات عبر واجهة GitHub فقط

ارفع الملفات بالمتصفح، ثم **Add file → Upload files**، وفعّل Pages كما في الخطوة 2.

## عدّاد المنضمين إلى الحملة

- يظهر في الهيدر: **«N منضمّاً»**.
- عدّاد **عام لكل الزوار** (وليس محلياً) عبر خدمة Abacus المجانية بلا حساب ولا مفاتيح.
- يُحتسب الزائر **مرة واحدة كل 5 دقائق كحد أدنى**:
  - تحديث الصفحة أو التنقل داخلها أو فتح تبويب جديد قبل انقضاء 5 دقائق → قراءة فقط، بلا زيادة.
  - بعد مرور 5 دقائق أو أكثر → تُحتسب زيارة جديدة.
- الوقت محفوظ في `localStorage`، فيصمد حتى بعد إغلاق المتصفح أو إعادة تشغيل الجهاز.
- يحتفظ بآخر قيمة في `localStorage` حتى لو تعطّلت الخدمة مؤقتاً.
- لتغيير مساحة العدّاد أو مدة النافذة: عدّل `JOINERS_API` و`JOINERS_WINDOW` في `assets/js/app.js`.

> تنبيه: العدّاد يقيس عدد الزيارات، وهو ليس سجلاً موثّقاً للمنضمين.
> التسجيلات الحقيقية تبقى في النموذج وقاعدة `submissions.md`.
